# Acaddem - Учебный Центр с Геймификацией 🚀

Acaddem — это современная платформа для образовательных центров с элементами геймификации. Платформа объединяет учеников, преподавателей и менеджеров, предоставляя каждому удобный и функциональный интерфейс для управления учебным процессом, отслеживания прогресса и повышения мотивации через систему наград.

## 🌟 Ключевые возможности

### Для учеников (Геймификация и Прогресс)
* **Панель управления**: Отображение баланса монет, заработанного опыта (XP) и глобального рейтинга.
* **Каталог курсов и запись**: Возможность просматривать доступные онлайн/оффлайн курсы и подавать заявку в группы.
* **Уведомления**: Моментальные оповещения о новых оценках, подтвержденных заявках и покупках.
* **Оценки**: Просмотр полученных оценок от преподавателей. Каждая положительная оценка приносит монеты и XP.
* **Магазин (Store)**: Заработанные монеты можно тратить на реальные или виртуальные товары в магазине центра (мерч, скидки и т.д.).

### Для преподавателей
* **Мои группы**: Просмотр назначенных групп, расписания и списка учеников.
* **Управление уроками**: Создание новых уроков.
* **Выставление оценок**: Удобный интерфейс для оценивания учеников. Выставленная оценка автоматически конвертируется в XP и монеты для ученика.
* **Рейтинги групп**: Отслеживание успеваемости учеников внутри конкретной группы.

### Для менеджеров (Администрирование)
* **Пользователи**: Управление аккаунтами (активация новых учеников, деактивация, сброс паролей).
* **Курсы и группы**: Создание курсов, формирование групп, назначение преподавателей.
* **Заявки (Enrollments)**: Одобрение или отклонение заявок учеников на присоединение к группе с автоматическим контролем свободных мест.
* **Магазин и заказы**: Добавление товаров в магазин, контроль складских запасов, управление заказами (выдача товаров ученикам, отмена).
* **Аудит оценок**: Полный контроль за выставленными оценками, возможность отмены оценки с автоматическим перерасчетом опыта и монет ученика (с указанием причины).

## 🛠 Технологический стек

### Бэкенд
* **FastAPI** — высокопроизводительный веб-фреймворк для создания API.
* **SQLAlchemy** — ORM для работы с базой данных.
* **SQLite** — легковесная база данных (настроено для локальной разработки).
* **PyJWT & Passlib** — аутентификация и безопасное хэширование паролей.
* Архитектура приложения разбита на модули (routers, models, schemas, core).

### Фронтенд
* **React 18** — библиотека для создания пользовательских интерфейсов.
* **Vite** — современный и быстрый сборщик.
* **React Router v6** — маршрутизация (роутинг).
* **Tailwind CSS** — утилитарный CSS-фреймворк для стилизации (v4).
* **Zustand** — легковесный стейт-менеджер (хранение данных пользователя и уведомлений).
* **Axios** — HTTP-клиент с настройкой интерцепторов для автоматического обновления токенов (Refresh Token).
* **Lucide React** — красивые и современные иконки.

## 🚀 Установка и запуск (Локально)

### 1. Клонирование репозитория
```bash
git clone https://github.com/asaddd404/coins.git
cd coins
```

### 2. Запуск Бэкенда (Backend)
Требуется Python 3.10+
```bash
cd backend
python -m venv venv
venv\Scripts\activate      # Для Windows
# source venv/bin/activate # Для Mac/Linux

pip install -r requirements.txt

# Наполнение базы данных тестовыми данными (опционально)
python seed.py

# Запуск сервера
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
Бэкенд будет доступен по адресу `http://localhost:8000`. Swagger-документация API: `http://localhost:8000/docs`

### 3. Запуск Фронтенда (Frontend)
Требуется Node.js 18+
```bash
cd frontend
npm install

# Запуск Vite сервера для разработки
npm run dev
```
Фронтенд будет доступен по адресу `http://localhost:5173`.

## 🛡 Безопасность и Архитектура
* **JWT Токены**: Используется пара Access/Refresh токенов. При истечении Access-токена фронтенд автоматически обновляет его, обеспечивая бесшовный пользовательский опыт.
* **Ролевая модель**: Доступ к API защищен на уровне ролей (student, teacher, manager).
* **Soft Delete**: Многие сущности не удаляются физически, а помечаются как неактивные (`is_active = False`) для сохранения целостности истории (например, оценок и покупок).
